REGRA 1 — CARD DE OFERTA E PLANOS

O plano de entrada (mais barato) deve listar apenas os itens principais do produto, sem bônus

O plano completo deve listar os itens principais + todos os bônus, destacados com um ícone diferente (presente) dos itens principais (check)

REGRA 2 — CARD DE OFERTA E PLANOS

Na hierarquia dos planos, o básico sempre é primeiro que o completo.

REGRA 3 — CARROSSÉIS

Os carrosséis nunca devem ser estáticos, precisam ser animados contínuos com velocidade de movimento rápido.
